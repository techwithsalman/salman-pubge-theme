# Salman Pubge Theme

Salman Khan's existing interactive portfolio with a cinematic PUBG-inspired visual theme. This is an independent creative portfolio, not an official PUBG website.

## Local preview

Requires Python 3. From this repository directory:

```sh
python 2mcrafters.com/serve.py 8081
```

Open http://localhost:8081/mohamedandaloussi/ in a browser. The included server handles the downloaded Next.js assets, images and routes; opening HTML directly is insufficient.

## Current version

- Eight real portfolio projects and their case studies are preserved.
- Phase 5.1 uses the supplied day/night TV images and footer image, with scoped media and phone styling in `2mcrafters.com/theme/pubg.css`.
- The TV retains live video playback and its original scroll-driven day/night and shutdown states.
- Contact forms open an email draft; they do not send mail from a backend.
- Generated gallery art is decorative, not presented as client work.
